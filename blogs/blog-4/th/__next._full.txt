24:T1ca3,<h1>ทำแอป Android ตัวเดียวให้พูดได้ทั้งอังกฤษ พม่า และไทย</h1>
<p>การแปลแอปฟังดูเหมือนงานแค่เรื่อง string: ก๊อป <code>strings.xml</code> ส่งให้คนที่
พูดภาษานั้น จบ แต่พอเปิด build ภาษาพม่า ปุ่มครึ่งหนึ่งตัวอักษรโดนตัด build
ภาษาไทยตัดบรรทัดกลางพยางค์ ส่วนภาษาอังกฤษก็โผล่ "1 items" ออกมา นี่คือ
สิ่งที่ผมเช็กทุกครั้งเมื่อแอปต้องรองรับภาษาอังกฤษ พม่า และไทย</p>
<h2>String: หนึ่งภาษาหนึ่งโฟลเดอร์ และห้ามต่อประโยค</h2>
<ul>
<li><code>values/</code> เก็บภาษาอังกฤษ ซึ่งเป็น fallback ของ string ที่ยังไม่ได้แปลด้วย
<code>values-my/</code> คือภาษาพม่า และ <code>values-th/</code> คือภาษาไทย</li>
<li>อย่าประกอบประโยคจากชิ้นส่วน "Paid " + name + " today" ใช้ได้แค่ใน
ภาษาอังกฤษ ภาษาพม่าและไทยเรียงกริยากับชื่อต่างกัน ให้ใช้ string เดียว
ที่มี placeholder: <code>&#x3C;string name="paid_today">จ่ายให้ %1$s แล้ววันนี้&#x3C;/string></code></li>
<li>ใส่ comment เหนือแต่ละ string เพื่อให้บริบทกับคนแปล "Back" ที่เป็นปุ่ม
กับ "back" ที่แปลว่าหลัง เป็นคนละคำกันในภาษาไทย</li>
</ul>
<h2>Plural ไม่เหมือนกันทุกภาษา</h2>
<p>ภาษาอังกฤษต้องมี <code>one</code> และ <code>other</code> ส่วนภาษาพม่าและไทยไม่เปลี่ยนรูปคำนาม
ตามจำนวน จึงใช้แค่ <code>other</code> แต่ก็ควรประกาศ plural ให้ถูกต้องอยู่ดี เพื่อให้
แต่ละภาษาได้กฎของตัวเอง:</p>
<pre><code class="language-xml">&#x3C;plurals name="items_count">
    &#x3C;item quantity="one">%d item&#x3C;/item>
    &#x3C;item quantity="other">%d items&#x3C;/item>
&#x3C;/plurals>
</code></pre>
<p>ใน <code>values-my/</code> และ <code>values-th/</code> entry เดียวกันจะมีแค่ <code>other</code> ตัวเดียว
พอเรียก <code>pluralStringResource(R.plurals.items_count, n, n)</code> ก็แสดงถูก
ทั้งสามภาษา</p>
<h2>ให้ผู้ใช้เลือกภาษาเอง</h2>
<p>คนในพม่าและไทยหลายคนตั้งภาษาโทรศัพท์เป็นอังกฤษ แต่อยากอ่านแอปเป็น
ภาษาของตัวเอง หรือกลับกัน Android 13 เพิ่มการตั้งค่าภาษารายแอป และ
AppCompat ก็ทำให้ API เดียวกันใช้ได้บนเวอร์ชันเก่าด้วย:</p>
<pre><code class="language-kotlin">AppCompatDelegate.setApplicationLocales(
    LocaleListCompat.forLanguageTags("my")
)
</code></pre>
<p>เพิ่ม <code>locales_config.xml</code> ที่มี <code>en</code>, <code>my</code> และ <code>th</code> แล้วแอปจะไปโผล่ในหน้า
App languages ของระบบด้วย</p>
<h2>ส่วนที่ยากจริงคือตัวอักษร</h2>
<blockquote>
<p>การแปลทำให้คำถูกต้อง แต่ typography เป็นตัวตัดสินว่าคนจะอ่านออก

</blockquote>

<li><strong>ตัวเลขและวันที่</strong> format ด้วย locale ของผู้ใช้ (<code>NumberFormat</code>,
<code>DateTimeFormatter</code>) แทนการเขียน pattern เอง เครื่องที่ตั้งเป็นไทยอาจใช้
ปีพุทธศักราช</li>
</ul>
